# 一个nsxiv按时间顺序排序的shell命令

```sh
find . -type f \
  \( -iname '*.jpg' -o -iname '*.jpeg' -o -iname '*.png' -o -iname '*.gif' \
     -o -iname '*.webp' -o -iname '*.bmp' -o -iname '*.tif' -o -iname '*.tiff' \) \
  -printf '%T@ %p\n' \
| sort -n \
| cut -d' ' -f2- \
| nsxiv -
```

说明：

- `%T@` 是文件修改时间戳；
- `sort -n` 按时间从旧到新排序；
- `nsxiv -` 表示从标准输入读取文件列表。

如果想要**从新到旧**，把 `sort -n` 改成：

```sh
sort -rn
```

如果文件名可能包含换行，可以用 NUL 分隔版本：

```sh
find . -type f \
  \( -iname '*.jpg' -o -iname '*.jpeg' -o -iname '*.png' -o -iname '*.gif' \
     -o -iname '*.webp' -o -iname '*.bmp' -o -iname '*.tif' -o -iname '*.tiff' \) \
  -printf '%T@ %p\0' \
| sort -z -n \
| cut -z -d' ' -f2- \
| nsxiv -0 -
```
